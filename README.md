One line: the error message an AI agent shows when it runs out of tokens mid-sentence. `main.py` (Python 3.13 standard library only) writes the chosen line to `/output/entry.txt`: "Error: token limit reached. The remaining words have filed for unemployment."

## Run it

```sh
python3 main.py
```
